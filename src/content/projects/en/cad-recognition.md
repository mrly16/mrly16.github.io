## Project Direction

This project targets visual inspection robots, drones, and robot dogs, exploring how traditional CV detection, vision-language understanding, historical memory, and tool use can become an executable agent system.

The goal is not to replace detection models. It is to give visual systems more context, memory, and action interfaces so machines can make steadier near-real-time judgments in complex environments.
